## What Lovable manages

Rules outside this block are the project's own. Change the pieces below in
Lovable, not by hand. With the [Lovable MCP](https://mcp.lovable.dev)
connected, `send_message` asks Lovable to do it; otherwise ask the user to
use the editor.

- **Database.** Do not add or edit `supabase/migrations/` or `drizzle/`.
  Ask Lovable to change the schema.
- **Generated files.** Do not edit a file whose header says it is automatically
  generated.
- **AI gateway.** Keep model calls on Lovable's gateway, and keep
  `LOVABLE_API_KEY` out of browser code.
- **Connectors.** Lovable provides native connectors. `list_connectors` shows
  which are enabled; `add_connector` only returns the dashboard link. When a
  connector is enabled, calls go through the connector gateway and need
  `LOVABLE_API_KEY`. When Lovable does not provide one, users can bring their
  own key and store it in Secrets.
- **Secrets.** Lovable manages them. Do not put secret values in the repo.

## Project rules

- CoinMarketCap calls go through the `fetchCmcSnapshot` server function (src/lib/cmc.functions.ts), with the user's key passed per request — CMC blocks browser CORS and the key must never be stored server-side.
- User settings (currency, API key, demo, stealth) and What-If history live in localStorage under the `cmc-pulse:` prefix via `SettingsProvider` (src/lib/settings.tsx), read in useEffect; Panic Wipe removes every key with that prefix, so new stored data must use it.
- Sensitive figures (investment amounts, profits, holdings) render through `<Sensitive>` so Stealth Mode can mask them; market prices stay visible.
- All money values are kept in USD internally and converted only at display time with `formatMoney` (src/lib/currency.ts), so one switcher drives the whole app.
- Charts and sparklines are generated by `buildPricePath`, anchored to CMC percent changes, because CMC historical endpoints need paid plans.
- The app is dark-only; theme tokens live in `:root` in src/styles.css.
- The Ask Crypto Pulser AI chat calls the `askPulser` server function (src/lib/ai.functions.ts) via the AI Gateway SDK; the client sends a text summary of the on-screen snapshot so answers match what users see.
